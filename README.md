# 📊 Sales Data Analysis

## Project Overview
This project analyzes sales data using Python to understand business performance and identify sales trends and insights.

## Objectives
- Analyze overall sales performance
- Calculate total sales and total profit
- Analyze sales by region and category
- Identify top-performing products
- Analyze monthly sales trends
- Calculate profit margin
- Create visualizations

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook / Kaggle

## Dataset
The dataset contains Order ID, Order Date, Region, Category, Product, Quantity, Unit Price, Discount, Sales, Cost, and Profit.

## Analysis
- Data cleaning
- Missing-value and duplicate checks
- KPI calculation
- Sales by region
- Sales by category
- Sales by product
- Monthly sales
- Profit analysis

## Key Skills
Python, Pandas, NumPy, Data Cleaning, EDA, KPI Analysis, Business Analysis, Data Visualization
